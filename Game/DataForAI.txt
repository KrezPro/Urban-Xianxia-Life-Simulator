ВЫУЧЕННЫЕ УРОКИ:
1. Metro Bundler может падать без babel-preset-expo в devDependencies.
2. Для react-native-mmkv v4+ babel-плагин не нужен, достаточно babel-preset-expo.
3. index.ts должен вести на src/App.tsx, дублирующий App.tsx в корне нужно удалять.
4. XML-парсер может ломаться о знак меньше в коде. Использовать инверсию условий через знак больше.
5. Если файл импортируется, но отсутствует, его нужно создать немедленно.
6. Route names нельзя локализовать. Нужны стабильные английские ключи.
7. BigInt нельзя безопасно хранить напрямую. Используем string и safeBigInt.
8. FlashList обязателен для больших списков.
9. AsyncStorage не использовать для глобального состояния.
10. Для BigInt-прогресса нельзя наивно делить BigInt. Нужен безопасный getBigIntProgress.
11. UI-кит должен быть в components/ui/index.tsx, чтобы экраны не дублировали кнопки и карточки.
12. Утилиты должны быть доступны через utils/helpers.ts, так как экраны и сервисы уже импортируют именно его.
13. Если components/ui/index.tsx отсутствует, экраны с Button/Card/ProgressBar/StatRow не соберутся.
14. Для структуры проекта нужны короткие комментарии: файл // назначение.
15. Если вкладка исчезла, нужно проверять TabNavigator и наличие соответствующего экрана в src/screens/.
16. При восстановлении большого блока файлов сначала создаются зависимости (types, helpers, Theme, stores, services, locales), затем экраны и навигация.
17. App должен ждать гидратации всех критичных сторов: player, locale.
18. Уведомления должны использовать safe-area insets, иначе камера/notch может перекрывать текст.
19. Чтобы интерфейс не дергался от уведомлений, уведомления должны быть абсолютным overlay, а основной экран должен иметь постоянный верхний резерв высоты.
20. Для адаптации под телефоны и планшеты нужно использовать Dimensions, PixelRatio, scaleSize, scaleFont, getContentMaxWidth и ограничивать ширину контента.
21. Длинный текст уведомления лучше показывать numberOfLines=3 и уменьшать fontSize для длинных строк, чтобы текст помещался в фиксированную область.
