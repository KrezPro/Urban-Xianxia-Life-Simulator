ВЫУЧЕННЫЕ УРОКИ:

1. Ошибка Metro Bundler (TransformError Cannot find module 'babel-preset-expo') при использовании Custom Dev Client возникает, если пресет отсутствует в devDependencies. Его всегда нужно добавлять.
2. При сборке custom dev client с react-native-mmkv v4+ плагин react-native-mmkv/babel больше не требуется, достаточно babel-preset-expo.
3. Чтобы избежать дублирования точек входа, Game/index.ts должен указывать строго на Game/src/App.tsx, а Game/App.tsx нужно удалять из файловой системы.
4. Ошибка XML syntax error возникает из-за использования знака меньше в JS/TS коде. Использовать инверсию условий через знак больше.
5. Если файл импортируется, но отсутствует, его нужно создать немедленно.
6. Route names нельзя локализовать. Нужны стабильные английские ключи, а видимые подписи брать из tab_bar в ui.json.
7. BigInt нельзя безопасно сериализовать напрямую в JSON/MMKV. Используем string и safeBigInt.
8. FlashList обязателен для больших списков.
9. AsyncStorage не использовать для глобального состояния.
10. Для социального слоя offline-first сначала создаются types, helpers, mmkvStorage, useLocaleStore, socialService, useSocialStore, data и locales, затем экран SectScreen и навигация.
11. Секты и рейтинги должны быть data-driven: шаблоны сект в sects.json, seed-рейтинг в rankings.json.
12. Инвайт-коды должны быть короткими и безопасными: без O, 0, I, 1, L, только A-Z и 0-9.
13. Секта игрока должна переживать перезапуск приложения через persist в MMKV.
