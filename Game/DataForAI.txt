ВЫУЧЕННЫЕ УРОКИ:
1. Ошибка Metro Bundler (TransformError Cannot find module 'babel-preset-expo') при использовании Custom Dev Client возникает, если пресет отсутствует в devDependencies. Его всегда нужно добавлять.
2. При сборке custom dev client с react-native-mmkv v4+ плагин react-native-mmkv/babel больше не требуется, достаточно babel-preset-expo.
3. Чтобы избежать дублирования точек входа, Game/index.ts должен указывать строго на Game/src/App.tsx, а Game/App.tsx нужно удалять из файловой системы.
4. Ошибка XML syntax error возникает из-за использования знака меньше в JS/TS коде. В генерации следует инвертировать условия и использовать строго знак больше.
5. Если файл импортируется в нескольких местах, но отсутствует в контексте, его нужно создать в первой же генерации. В этом проекте таким файлом был useLocaleStore.ts.
6. Route names в React Navigation нельзя делать локализованными строками. Нужно использовать стабильные английские ключи, а отображаемый текст брать из tabBarLabel и locales.
7. BigInt нельзя безопасно сериализовать напрямую в JSON/MMKV. В сторах и данных используем string, а расчеты делаем через safeBigInt.
8. Для больших списков FlashList обязателен. Журнал событий остается основным кандидатом, а будущие рейтинги при росте числа записей также нужно переводить на FlashList.
9. AsyncStorage удален из package.json. Если какая-либо зависимость требует его, нужно находить альтернативу или изолировать в нативный модуль, но не использовать для глобального состояния.
10. Для прогресс-баров на BigInt нельзя напрямую делить BigInt. Нужно приводить к Number только после проверки диапазона или использовать приближение по длине строки.
