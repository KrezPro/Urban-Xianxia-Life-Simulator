Уроки:
1. При проблеме "Open up App.tsx..." в новых версиях Expo, помимо экспорта `export default App;`, полезно явно использовать `registerRootComponent(App)`, чтобы перехватить точку входа.
2. Обращать внимание на регистр папки проекта (Game vs game) при интеграции с внешними bat-скриптами.
3. Во избежание проблем с маршрутизацией Metro, корневой UI лучше временно держать в корневом App.tsx до внедрения React Navigation.
