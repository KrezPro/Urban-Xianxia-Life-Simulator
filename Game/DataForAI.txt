ВЫУЧЕННЫЕ УРОКИ:

1. Ошибка Metro Bundler (TransformError Cannot find module 'babel-preset-expo') при использовании Custom Dev Client возникает, если пресет отсутствует в devDependencies. Его всегда нужно добавлять.
2. При сборке custom dev client с react-native-mmkv v4+ плагин react-native-mmkv/babel больше не требуется, достаточно babel-preset-expo.
3. Чтобы избежать дублирования точек входа, Game/index.ts должен указывать строго на Game/src/App.tsx, а Game/App.tsx нужно удалять из файловой системы.
4. Ошибка XML syntax error возникает из-за использования знака меньше в JS/TS коде. Использовать инверсию условий через знак больше.
5. Если экраны или хуки импортируют useLocaleStore, файл useLocaleStore.ts должен существовать до сборки.
6. Русские route names в React Navigation ломают масштабируемость и локализацию. Нужно использовать английские ключи, а видимые подписи брать из словарей.
7. App должен ждать гидратации не только player-storage, но и locale-storage, чтобы не мигать неправильным языком.
8. useIdleProgress должен использовать словари ui.idle, а не хардкодить текст оффлайн-наград.
9. MMKV-адаптер должен сохранять интерфейс storage и zustandStorage, чтобы не ломать persist-конфигурацию сторов.
