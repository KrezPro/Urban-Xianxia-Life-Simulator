# ВЫУЧЕННЫЕ УРОКИ (AiCoder)

## Урок 1: Hermes и таблицы GameConstants
Чтение отсутствующих таблиц GameConstants (например, EVENT_* таблиц) напрямую крашит Hermes
ошибкой "Cannot convert undefined value to object". Все таблицы читать ТОЛЬКО через
tableNumber(table, key, fallback) с fallback-значением.

## Урок 2: Навигация и журнал
navigation.navigate('Log') запрещён: журнал открывается ТОЛЬКО модально из LifeScreen
(LogScreen с onClose). Вкладка Log скрыта из tab bar.

## Урок 3: NotificationToast
Таймер автоскрытия запускается от момента монтирования тоста, а не от createdAt,
иначе уведомление исчезает мгновенно.

## Урок 4: Адаптивность вкладки Мир (ШАГ 27 -> ШАГ 28)
Ошибка: auto-ScrollView "fallback" + порог compact 780pt.
- Реальные телефоны имеют окно 800-844pt (360x800 dp даёт около 810pt), поэтому compact НЕ
  включался, контент не сжимался и не вмещался.
- Fallback включал ScrollView: пользователь видел прокрутку вместо сжатия (нарушение
  договорённости "всё закреплено и влазит на любом экране").
- Большой paddingBottom (84-96) + flex-остаток cardsArea давали мёртвую чёрную полосу снизу.
Решение: ScrollView во вкладке Мир НЕ использовать вообще. Два порога плотности:
compact при высоте окна ниже 900pt (все телефоны) и tiny ниже 700pt (очень маленькие).
Контент сжимается (dense StatRow, меньшие paddings/шрифты/бейджи) и закрепляется.
paddingBottom — только клиренс под перетаскиваемый FAB: 96 / 72 / 64 по тирсам.
LifeAvatar принимает числовой size (76 / 64 / 54) вместо булева compact.

## Урок 5: Приоритет договорённостей по UX
Если пользователь договорился "контент закреплён и влезает на любой экран", нельзя подменять
это скроллом. Лучше сжать типографику и отступы (тирсы плотности), чем включать прокрутку.
Пороги адаптивности выбирать по реальным размерам окон устройств (800-844pt), а не "на глаз".

## Урок 6: XML-безопасность ответов AiCoder
Вне CDATA-секций (commit_message, служебный текст) ЗАПРЕЩЕНО использовать символ "меньше"
перед числами или словами: парсер принимает его за начало XML-тега и падает с ошибкой
"invalid XML name". Внутри commit_message писать словами: "порог 900pt", "ниже 700pt".
