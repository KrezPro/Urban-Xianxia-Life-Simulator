# АРХИТЕКТУРНАЯ БИБЛИОТЕКА ПРОЕКТА

1. Стейт-менеджмент: строго Zustand. Сторы: Player, Event, Inventory, Locale, Social.
2. Хранилище: строго react-native-mmkv через zustandStorage. Использовать паттерн hasHydrated.
3. Отрисовка списков: FlashList для журнала и рейтингов. FlatList для больших списков не использовать.
4. Типизация: strict TypeScript, интерфейсы лежат в src/types/index.ts.
5. Большие числа: хранить как string, парсить в BigInt через safeBigInt.
6. UI: функциональные компоненты. Текст только из locales/{lang}/*.json.
7. Баланс и контент: данные лежат в src/data/*.json.
8. Навигация: route names только английские: Life, Dao, Store, Log, Sect.
9. Социальный слой: offline-first секты, локальные инвайты, локальный рейтинг.
10. Рейтинги: score хранится как string, сортировка выполняется через BigInt.
11. Локализация: useLocaleStore хранит выбранный язык ru/en.
12. Offline-симуляция секты ограничена SOCIAL_MAX_OFFLINE_SECONDS.
13. MMKV основной storage; memory-fallback допустим только для аварийных сред.
14. Theme.ts: единая темная тема для всего UI.
15. helpers.ts: единый модуль для форматирования, BigInt-утилит и random-утилит.
16. socialService.ts: генерация инвайтов, создание сект, NPC-участники, offline-прогресс, рейтинг.
17. SectScreen содержит два режима: "Моя секта" и "Рейтинг".
