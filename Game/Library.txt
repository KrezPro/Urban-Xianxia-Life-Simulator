# АРХИТЕКТУРНАЯ БИБЛИОТЕКА ПРОЕКТА
1. Стейт-менеджмент: только Zustand. Сторы: Player, Event, Inventory, Locale, Social, Notification, Techniques, Lifestyle.
2. Хранилище: только react-native-mmkv через zustandStorage. Паттерн hasHydrated обязателен.
3. Списки: FlashList для журнала и потенциально больших рейтингов. FlatList для логов не использовать.
4. Типизация: strict TypeScript, интерфейсы в src/types/index.ts.
5. Большие числа: хранить как string, считать через safeBigInt.
6. UI: функциональные компоненты. Текст только из locales/{lang}/*.json.
7. Баланс и контент: data/*.json.
8. Навигация: route names только английские: Life, Dao, Activities, Store, Log, Sect.
9. Социальный слой: offline-first секты, локальные инвайты, локальный рейтинг.
10. Рейтинги: score как string, сортировка через BigInt.
11. Локализация: useLocaleStore хранит ru/en.
12. Offline-симуляция секты ограничена SOCIAL_MAX_OFFLINE_SECONDS.
13. MMKV основной storage; memory-fallback только для аварийных сред.
14. Theme.ts: единая темная тема для всего UI.
15. components/ui/index.tsx: единый UI-кит. Использовать Button, Card, ProgressBar, StatRow вместо ручных стилей.
16. utils/helpers.ts: единый модуль для formatLargeNumber, BigInt-утилит и random-утилит.
17. Если экран импортирует helpers или UI-кит, эти файлы должны существовать до запуска сборки.
18. Новые файлы всегда получать короткое описание в структуре проекта.
19. Кнопки должны поддерживать варианты primary, secondary, danger, gold, ghost, small, disabled и icon.
20. ProgressBar должен безопасно принимать progress от 0 до 1 и сам обрезать выходящие значения.
21. Вкладка Sect обязана присутствовать в TabNavigator как отдельный английский route name "Sect".
22. SectScreen содержит два режима: "Моя секта" и локальный рейтинг.
23. SafeAreaView использовать только из react-native-safe-area-context, SafeAreaProvider оборачивает App.
24. StatRow поддерживает onPress и onLongPress для показа подсказок по long-press.
25. NotificationHost размещается глобально в App.tsx поверх NavigationContainer, использует absolute positioning с safe-area insets.
26. Подсказки хранятся в ui.json под ключом hints для каждого стата/фокуса.
27. Кнопка журнала размещается в шапке LifeScreen рядом с переключателем языка. Маршрут Log сохраняется в TabNavigator, но скрыт из tab bar через tabBarButton: () => null.
28. DraggableGrowButton — перетаскиваемая кнопка взросления. Короткое нажатие вызывает growOlder, перетаскивание выполняется PanResponder в пределах LifeScreen.
29. IconButton добавлен в UI-кит для компактных кнопок без текста.
30. Draggable FAB имеет zIndex 900, NotificationHost остается выше с zIndex 1000.
31. LifeScreen использует обычный View вместо ScrollView, если прокрутка не требуется; DraggableGrowButton остается абсолютным overlay.
32. Здоровье игрока разделено на health (текущее) и maxHealth (максимальное). Во вкладке Мир в списке характеристик отображается maxHealth.
33. Техники Дао хранятся в useTechniquesStore как levels: Record<string, number>, сбрасываются при реинкарнации.
34. Активности образа жизни хранятся в useLifestyleStore как selected: LifestyleSelection, сбрасываются при реинкарнации.
35. Годовой цикл рассчитывается в useYearlyCycle и использует processLifestyleYear из utils/gameplayUtils.ts.
36. Карма-баффы стали многоуровневыми: quantity в useInventoryStore означает текущий уровень баффа.
37. Локализация вкладок вынесена в locales/{lang}/navigation.json, техники в dao.json, активности в activities.json, дополнительные ключи магазина в store.json.
38. Все проценты в игре хранятся как basis points (bps): 1% = 100 bps, 100% = 10000 bps.
39. CollapsibleSection — раскрывающийся UI-компонент для категорий активностей.
40. useYearlyCycle обрабатывает: подписки, доход, здоровье, Ци, порталы, события и отключение неоплаченных активностей.
41. При реинкарнации техники и активности сбрасываются, карма-баффы сохраняются с уровнями.
42. gameplayUtils.ts содержит все математические расчёты годового цикла, техник и карма-баффов.
