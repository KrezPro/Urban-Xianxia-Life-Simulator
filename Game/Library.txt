# АРХИТЕКТУРНАЯ БИБЛИОТЕКА ПРОЕКТА

1. Стейт-менеджмент: Строго Zustand. Состояние разбивается на логические модули (Player, Event, Inventory).
2. Хранилище: Строго react-native-mmkv (синхронное, быстрое, паттерн hasHydrated).
3. Отрисовка списков: Использовать @shopify/flash-list (FlatList запрещен для логов).
4. Типизация: Strict TypeScript, интерфейсы лежат в src/types/.
5. Большие числа (Ци): Использовать тип string для хранения в MMKV, парсить в BigInt при расчетах дельты/прогресса.
6. UI: Functional Components (FC) + Hooks.
7. Баланс: Данные (шансы, пилюли, события) лежат в src/data/ (json/ts).
