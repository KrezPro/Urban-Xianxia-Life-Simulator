# АРХИТЕКТУРНАЯ БИБЛИОТЕКА ПРОЕКТА
1. Стейт-менеджмент: только Zustand. Сторы: Player, Event, Inventory, Locale, Notification.
2. Хранилище: только react-native-mmkv через zustandStorage. Паттерн hasHydrated обязателен.
3. Списки: FlashList для журнала и потенциально больших рейтингов. FlatList для логов не использовать.
4. Типизация: strict TypeScript, интерфейсы в src/types/index.ts.
5. Большие числа: хранить как string, считать через safeBigInt.
6. UI: функциональные компоненты. Текст только из locales/{lang}/*.json.
7. Баланс и контент: data/*.json.
8. Навигация: route names только английские.
9. Локализация: useLocaleStore хранит ru/en.
10. MMKV основной storage; memory-fallback только для аварийных сред.
11. Theme.ts: единая темная тема для всего UI.
12. components/ui/index.tsx: единый UI-кит. Использовать Button, Card, ProgressBar вместо ручных стилей.
13. utils/helpers.ts: единый модуль для formatLargeNumber, BigInt-утилит и random-утилит.
14. utils/layout.ts: все адаптивные размеры считать через scaleSize/scaleFont, getContentMaxWidth, getHorizontalPadding, getNotificationAreaHeight.
15. Уведомления: показывать только одно активное уведомление. NotificationHost размещается глобально поверх NavigationContainer и учитывает safe-area insets.
16. Вкладка Мир: верхняя область экрана должна иметь постоянный резерв под уведомление, чтобы контент не дергался и камера/notch не перекрывали текст.
17. NotificationToast должен сам удаляться по истечении durationMs и поддерживать локализацию через messageKey/eventId.
18. Для планшетов контент центрируется и ограничивается по maxWidth, чтобы интерфейс не растягивался на весь экран.
